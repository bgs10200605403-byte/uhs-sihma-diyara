# UHS Sihma Diyara — GitHub Pages Static Website

यह version सीधे GitHub Pages पर चलने के लिए बनाया गया है। कोई npm, Node.js या build step आवश्यक नहीं है।

## Upload
Repository में इस folder की सभी files root में upload करें। पुराने `index.html` को replace करें और `CNAME` को रहने दें।

## GitHub Pages
Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

## Custom domain
Settings → Pages → Custom domain में `uhssihmadiyara.online` डालें। DNS में GitHub Pages के लिए GitHub के current A/AAAA records लगाएँ।

## Content update
HTML pages में placeholder text, notices, teachers, events और images बदले जा सकते हैं। `images/` में वास्तविक विद्यालय फोटो रखें।

## Important
Fake school photos, unverified results, phone numbers, email, principal/teacher names आदि publish न करें।
